## Review notes (App Review Information)

```
Eyes Buddy is a countdown timer. No account or login is needed.
Start a timer on the main screen. A Live Activity (Dynamic Island / Lock Screen) shows the
remaining time with a pair of eyes that turn red when time is up. A local notification with a
sound fires at the end (notification permission is requested on first launch).
The app uses no network connection and collects no data.
```
